# آموزش کلاس اول — اپلیکیشن آموزش الفبا و اعداد فارسی

اپلیکیشن **کاملاً آفلاین** آموزش الفبای فارسی و اعداد ۰ تا ۱۰۰ برای دانش‌آموزان کلاس اول دبستان ایران، ساخته‌شده با Flutter و آماده انتشار در کافه‌بازار.

[![Build APK](https://github.com/wizardtcman-design/aval_dabestan/actions/workflows/build-apk.yml/badge.svg)](https://github.com/wizardtcman-design/aval_dabestan/actions/workflows/build-apk.yml)

## ویژگی‌ها
- ۱۰۰٪ آفلاین: صدا، تصویر و محتوا داخل خود اپلیکیشن — بدون هیچ دسترسی اینترنتی
- آموزش حرف‌به‌حرف با تصویر، تلفظ، تمرین نوشتن نقطه‌چین و ۴ بازی برای هر حرف
- اعداد ۰ تا ۱۰۰ با شمارش تصویری، جدول کامل و بازی جفت‌یابی
- سیستم قفل مرحله‌ای: هر حرف بعد از تکمیل یادگیری حرف قبلی باز می‌شود
- صدا: فایل‌های ضبط‌شده داخل اپ (just_audio) با پشتیبان گویندهٔ سیستم (flutter_tts)
- ذخیره پیشرفت روی خود گوشی (Hive) — بدون سرور، بدون اینترنت
- فونت وزیرمتن، چیدمان کامل راست‌به‌چپ، پالت رنگی ملایم کودکانه

## ساختار پروژه
```
aval_dabestan/
├── .github/workflows/build-apk.yml   # ساخت خودکار APK روی هر push
├── android/                          # پروژه اندروید (gradle wrapper + keystore-ready)
├── assets/
│   ├── fonts/       # وزیرمتن (۴ وزن)
│   ├── icons/       # آیکون اپ
│   ├── images/      # تصاویر آموزشی حروف + ماسکات
│   └── sounds/      # صداها (آفلاین)
├── lib/
│   ├── main.dart / app.dart
│   ├── core/        # رنگ‌ها، تم، ابزارها
│   ├── data/        # محتوای حروف (۳۲+) و اعداد ۰-۱۰۰
│   ├── state/       # Provider پیشرفت (قفل مرحله‌ای) و تنظیمات
│   ├── services/    # صدا (just_audio + flutter_tts)، ذخیره‌سازی (Hive)
│   ├── screens/     # خانه، حروف، جزئیات حرف، اعداد، بازی‌ها، داشبورد والدین، تنظیمات
│   └── widgets/     # ویجت‌های مشترک (نوشتن نقطه‌چین، ستاره، کانفتی و...)
├── scripts/         # setup_github.sh ، push_to_github.sh ، build_apk.sh
└── push.sh          # push یک‌کلیکی به گیت‌هاب با توکن
```

## ساخت خودکار APK (GitHub Actions)
با هر push به `main`، سه خروجی خودکار ساخته می‌شود:
- `app-release.apk` (کامل) + نسخه‌های تفکیک‌شده بر اساس معماری (`--split-per-abi`، حجم کمتر) + `app-debug.apk`
- دانلود از تب **Actions** → آخرین اجرا → بخش **Artifacts**
- با زدن تگ نسخه، فایل‌ها در تب **Releases** منتشر می‌شوند:
  ```bash
  git tag v1.0.0
  ./push.sh "release: نسخه ۱.۰.۰"
  ```

## push یک‌کلیکی
```bash
./push.sh "پیام کامیت"
```
توکن به‌ترتیب از `GITHUB_TOKEN`، فایل `.github-token` (در .gitignore) یا ورودی دستی خوانده می‌شود و **هرگز** داخل ریپازیتوری ذخیره نمی‌شود.

## نکته انتشار در کافه‌بازار
در حال حاضر APK Release با کلید debug امضا می‌شود (قابل نصب و تست). برای انتشار، keystore اختصاصی ساخته و به‌صورت GitHub Secret به pipeline اضافه می‌شود — پوشه android از قبل برای این کار آماده است.
