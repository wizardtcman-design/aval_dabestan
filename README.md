# اول دبستان — اپلیکیشن آموزش الفبا و اعداد فارسی

اپلیکیشن **کاملاً آفلاین** آموزش الفبای فارسی و اعداد ۰ تا ۱۰۰ برای دانش‌آموزان کلاس اول دبستان، ساخته‌شده با Flutter و طراحی‌شده برای انتشار در کافه‌بازار.

[![Build APK](https://github.com/wizardtcman-design/aval_dabestan/actions/workflows/build-apk.yml/badge.svg)](https://github.com/wizardtcman-design/aval_dabestan/actions/workflows/build-apk.yml)

## ویژگی‌ها
- ۱۰۰٪ آفلاین: صدا، تصویر و محتوا داخل خود اپلیکیشن
- آموزش حروف با تصویر، تلفظ، تمرین نوشتن و ۴ بازی برای هر حرف
- آموزش اعداد ۰ تا ۱۰۰ با شمارش تصویری و بازی‌های تطبیق
- سیستم قفل مرحله‌ای: هر نشانه بعد از یادگیری نشانه قبلی باز می‌شود
- فونت خوانای وزیرمتن، راست‌به‌چپ، رنگ‌های ملایم کودکانه
- ذخیره پیشرفت کودک روی خود گوشی (بدون اینترنت، بدون سرور)

## ساختار پروژه
```
aval_dabestan/
├── .github/workflows/build-apk.yml   # ساخت خودکار APK روی هر push
├── assets/
│   ├── data/        # letters.json و numbers.json (محتوای آموزشی)
│   ├── fonts/       # وزیرمتن
│   ├── images/      # تصاویر آموزشی (فاز بعد)
│   └── audio/       # فایل‌های صوتی تلفظ (فاز بعد)
├── lib/
│   ├── main.dart            # نقطه شروع
│   ├── app.dart             # MaterialApp + راست‌به‌چپ
│   ├── theme/               # رنگ‌ها و تم
│   ├── models/              # Letter, NumberItem, Progress
│   ├── data/                # خواندن محتوا از JSON داخل اپ
│   ├── services/            # ذخیره پیشرفت و تنظیمات (shared_preferences)
│   └── screens/             # خانه، حروف، جزئیات حرف، اعداد، بازی‌ها، داشبورد والدین، تنظیمات
├── scripts/                 # اسکریپت‌های تولید محتوا
└── push.sh                  # push یک‌کلیکی به گیت‌هاب با توکن
```

## ساخت خودکار APK (GitHub Actions)
با هر push به شاخه `main`، هر دو نسخه APK به‌صورت خودکار ساخته می‌شوند:
- فایل `app-debug.apk` و `app-release.apk` در تب **Actions** → آخرین اجرا → بخش **Artifacts**
- با زدن تگ `v1.0.0` نسخه Release در تب **Releases** منتشر می‌شود:
  ```bash
  git tag v1.0.0
  ./push.sh "release: نسخه ۱.۰.۰"
  ```

## push یک‌کلیکی
```bash
./push.sh "پیام کامیت"
```
توکن به‌ترتیب از `GITHUB_TOKEN`، فایل `.github-token` (gitignore شده) یا ورودی دستی خوانده می‌شود. توکن **هرگز** داخل ریپازیتوری ذخیره نمی‌شود.

## ترتیب حروف
ترتیب فعلی حروف در `assets/data/letters.json` **الفبایی** است. برای هم‌تراز کردن دقیق با ترتیب درس‌به‌درس کتاب فارسی اول، کافی است آرایه همین فایل جابه‌جا شود — هیچ تغییری در کد لازم نیست (ترتیب، صفحات و قفل مراحل همه از همین فایل خوانده می‌شوند).
